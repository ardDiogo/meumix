# Modelos de e-mail do Supabase (MeuMix)

Supabase → **Authentication → Emails → Templates**. Para cada modelo, copie o **Subject** e cole o conteúdo do arquivo `.html` no **Body** (Message body). Salve cada um.

| Modelo no Supabase | Arquivo | Subject |
|---|---|---|
| Confirm signup | `confirm-signup.html` | Confirme seu cadastro no MeuMix |
| Invite user | `invite-user.html` | Você foi convidado para o MeuMix |
| Magic link | `magic-link.html` | Seu link de acesso ao MeuMix |
| Change email address | `change-email.html` | Confirme seu novo e-mail no MeuMix |
| Reset password | `reset-password.html` | Redefinir sua senha do MeuMix |
| Reauthentication | `reauthentication.html` | Seu código de confirmação do MeuMix |

O logo vem de `https://meumix.vercel.app/brand/logo.png` (precisa do site no ar). Cores: fundo #08090B, cartão #121419, laranja #FF6A00, texto #F5F5F5 / #A1A1AA.
