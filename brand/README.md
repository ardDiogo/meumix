# Marca MeuMix

- `originais/` — arquivos enviados (PNG com fundo preto). Fonte para gerar as versões abaixo.
- `public/brand/logo.png` — logo completo com fundo transparente (menu lateral, topo).
- `public/brand/simbolo.png` — apenas o "M", fundo transparente.
- `src/app/icon.png`, `src/app/favicon.ico` — favicon (gerado a partir de `originais/favicon.png`).
- `src/app/apple-icon.png` — ícone para iPhone (gerado a partir de `originais/icone.png`).

Quando houver versão vetorial (SVG) da marca, substitua os PNGs de `public/brand/`.
